# Mongo-DB-Utils

A lightweight Python module designed for managing MongoDB databases, performing CRUD operations, handling collections, and automating basic database connections smoothly.

## Key Features
* Easy connection management for local and remote MongoDB instances.
* Streamlined CRUD (Create, Read, Update, Delete) operation wrappers.
* Efficient handling of collection queries and document filtering.
* Optimized Python code structure for clean integration into existing projects.
